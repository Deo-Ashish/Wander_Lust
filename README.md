# StayNest 🏡

A full-stack property listing platform where users can discover, create, review, and manage accommodations. Built using Node.js, Express, MongoDB, and EJS following the MVC architecture.

## 🚀 Getting Started

### Install Dependencies

```bash
npm install
```

### Run the Application

```bash
node app.js
```

For development:

```bash
nodemon app.js
```

Open:

```text
https://staynest-ahym.onrender.com
```

---

## ✨ Features

* User Authentication & Authorization
* Create, Edit & Delete Listings
* Cloudinary Image Uploads
* Reviews & Ratings System
* Session Management
* Protected Routes
* Form Validation with Joi
* Responsive Bootstrap UI
* MVC Architecture
