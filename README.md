# StayNest 🏡

StayNest is a full-stack property discovery platform that connects travelers with unique accommodations around the world. Users can explore destinations, discover stays, share reviews, and manage their own property listings through a clean and intuitive interface.

## ✨ Features

### 👤 User Authentication
- Secure user registration and login
- Session-based authentication
- Password hashing and security
- Protected routes and authorization

### 🏠 Property Management
- Create property listings
- Edit listing details
- Delete listings
- Upload and manage property images
- View complete property information

### ⭐ Reviews & Ratings
- Add reviews and ratings
- Delete reviews
- Review validation
- Community-driven feedback system

### 🔍 Explore Properties
- Browse available stays
- Responsive property cards
- Detailed listing pages
- Location and pricing information

### 📱 Responsive Design
- Mobile-friendly interface
- Modern UI components
- Optimized user experience
